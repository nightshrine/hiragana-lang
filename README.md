# ひらがな言語

ひらがなだけで書けるプログラミング言語。

```
めも ふぃぼなっちすうれつ
「まえ」 は 0 。
「いま」 は 1 。
くりかえし 「かいすう」 を 0 から 10 ここから
  みせる 「まえ」 。
  「つぎ」 は 「まえ」 たす 「いま」 。
  「まえ」 は 「いま」 。
  「いま」 は 「つぎ」 。
ここまで

めも ふぃずばず
くりかえし 「かず」 を 0 から 30 ここから
  もし 「かず」 あまり 3 ひとしい 0 かつ 「かず」 あまり 5 ひとしい 0 ここから
    みせる "FizzBuzz" 。
  ここまで それとも 「かず」 あまり 3 ひとしい 0 ここから
    みせる "Fizz" 。
  ここまで それとも 「かず」 あまり 5 ひとしい 0 ここから
    みせる "Buzz" 。
  ここまで ちがえば ここから
    みせる 「かず」 。
  ここまで
ここまで
```

## 文法

### 語彙

| 意味 | 書き方 |
|---|---|
| 変数名 | `「かず」`（「」で囲む） |
| 文字列 | `"こんにちは"`（`"` で囲む） |
| 数値 | `10` `1.5`（全角も可） |
| 真偽値 / null | `ほんとう` `うそ` / `なし` |
| コメント | `めも` から行末まで |
| 文末 | `。` |
| 括弧 | `(` `)`（全角も可） |

### 文

| 意味 | 書き方 |
|---|---|
| 代入（初回が宣言を兼ねる） | `「かず」 は 10 。` |
| 出力 | `みせる 「かず」 。` |
| 条件分岐 | `もし 条件 ここから … ここまで それとも 条件 ここから … ここまで ちがえば ここから … ここまで` |
| 回数ループ（終了値は含まない） | `くりかえし 「かいすう」 を 0 から 10 ここから … ここまで` |
| 条件ループ | `あいだ 条件 ここから … ここまで` |

### 演算子（優先順位の高い順）

| 意味 | 書き方 |
|---|---|
| 符号反転 | `ひく 5` |
| 乗除・剰余 | `かける` `わる` `あまり` |
| 加減 | `たす` `ひく` |
| 大小比較 | `ちいさい`(<) `おおきい`(>) `いか`(<=) `いじょう`(>=) |
| 等値 | `ひとしい` |
| 論理積 | `かつ` |
| 論理和 | `または` |
| 代入 | `は` |

トークンの間の空白は任意（`「かず」は10。` でも可）。

## 開発

```sh
npm install
npm run dev          # Playground を localhost で起動
npm run cli -- examples/fibonacci.hira   # ブラウザなしで実行
npm run build        # 型チェック + dist/ を生成
```

## 構成

```
src/
├── lang/
│   ├── lexer.ts        ソース文字列 → Token[]（予約語表はここ）
│   ├── parser.ts       Token[] → Statement[]（AST）
│   └── interpreter.ts  Statement[] を評価して実行
├── main.ts             Playground の UI
└── cli.ts              Node から実行するための CLI
```

## デプロイ

`main` に push すると GitHub Actions が GitHub Pages へデプロイする（`.github/workflows/deploy.yml`）。
リポジトリの Settings → Pages → Source を「GitHub Actions」にしておくこと。
`vite.config.ts` の `base: './'` により、プロジェクトページ配下でもそのまま動く。
